# Nike Landing Page 

A modern, responsive Nike-inspired landing page built with **React**, **Vite**, and **Tailwind CSS**.

The project focuses on creating a clean user interface, reusable React components, and responsive layouts using Tailwind CSS.

##  Features

- Responsive design for different screen sizes
- Modern hero section with interactive shoe selection
- Popular products showcase
- Customer reviews section
- Services and special offers sections
- Newsletter subscription section
- Reusable React components
- Custom Tailwind CSS utilities and styling

##  Technologies

- React
- Vite
- Tailwind CSS v4
- JavaScript
- HTML5
- CSS3

##  Getting Started

To run this project locally:

**1. Clone the repository**

```bash
git clone https://github.com/navexdev/Nike
```

**2. Navigate to the project directory**

```bash
cd Nike
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the project.
